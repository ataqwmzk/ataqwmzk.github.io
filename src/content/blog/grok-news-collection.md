## 結論

**Grokの「オートメーション」に毎時ニュースを集めさせて、結果をGmailに届ける仕組みを作りました。** 分かったのは、次の3つです。

- 実行は予定より10分ほど遅れることがある
- 「過去1時間」と指定すると、遅れた分だけ取りこぼしが出る
- AIが書いたニュースは、そのまま信じず、出典で確かめる必要がある

## 全体の流れ

```
Grok（毎時・終日で自動実行）
　↓  Xの投稿 + Web を見てニュースを集める
Gmail にメールで届く
　↓  朝4:30・夕16:30（Claudeの定期タスク）
Claude が読んで要約・出典を確認
```

この記事は、いちばん上の「集めるところ」の話です。

## Grokにやらせたこと

| 項目 | 内容 |
|---|---|
| 頻度 | 毎時、終日 |
| 分野 | 国際・政治、経済・企業、テクノロジー・AI、科学・宇宙・医療、スポーツ、音楽、フェス・ライブ、映画・ドラマ・ゲーム、自然災害・気象、その他 |
| 件数 | 1分野につき最大2件 |
| 長さ | 2,500字以内 |
| 受け取り方 | メール（Gmail） |

Grokは、X（旧Twitter）の投稿を見られるのが強みです。ニュースが公式の記事になる前に、Xで先に流れることがあるからです。

## 指示文に入れたルール

| ルール | ねらい |
|---|---|
| 事実だけ書く。意見・予想は書かない | 話を盛らせない |
| 出典は個別の記事URLだけ。一覧ページやトップページは不可 | あとで確認できるようにする |
| ラベルを付ける：[公式]／[報道]／[X速報] | どれくらい確かな情報かを分ける |
| 本文とラベルを合わせる | Xの投稿だけなのに「公式発表」と断定しない |
| 新しいものだけ載せる | 古いニュースの使い回しを防ぐ |
| 1行目に「収集時刻」を書く | あとで時間帯ごとに整理できる |

## やってみて分かったこと

| 分かったこと | 起きたこと | 対応 |
|---|---|---|
| 実行が遅れる | 最初の1回が9分ほど遅れた。別の回では収集時刻が12:09だった | 遅れは仕方ないものとして受け入れる |
| 「過去1時間」だとすき間があく | 12:09に集めて、次が13:15なら、12:09〜12:15の6分が抜ける | 「過去90分」に変える（重複は要約側でまとめる） |
| メールが途中で切れる | 本文の最後に「Continue reading」と出て、全文が入らないことがあった | 文字数を2,500字以内に絞る |
| 実行のたびに選ぶニュースが変わる | 同じ指示文でも、載るニュースが回ごとに違う | 1回で全部を拾おうとしない。毎時の積み重ねで補う |

## 気をつけていること

- **AIの出力は、AI同士で採点させない。** 別のAIに「これ合ってる？」と聞いても、確かめたことにはなりません。公式発表や元の記事で確認します。
- **Xは速いが、盛った投稿も多い。** まとめ系のアカウントは、話を大きくすることがあります。だから[X速報]のラベルを付けて、確かなものと区別しています。
- **要約する側（Claude）でも、気になるものは出典を開いて確かめる。** 断定している文や、数字・発言が入っているものを優先します。

## まだ分からないこと

- 新しい指示文で、メールが途中で切れずに届くか（これから確認します）
- 「過去90分」にして、取りこぼしが実際に減るか
