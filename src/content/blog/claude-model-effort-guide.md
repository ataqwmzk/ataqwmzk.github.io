## 結論

**ふだんの質問はSonnet、考える作業はOpus中、上限が厳しいときの軽い用事はHaiku。** Sonnetの超高は、基本的には選ばなくて大丈夫です。

調べた日は2026年11月9日です。モデルの更新で数字や評価は変わることがあるので、使うときは最新の情報も確認してください。

## 3つのモデルの違い

| | Haiku 5.5 | Sonnet 5.5 | Opus 5.5 |
|---|---|---|---|
| 賢さ | ふつう | 高い | いちばん高い |
| 速さ | いちばん速い | 速い | ふつう |
| 値段 | Sonnetの約1/20 | Opusの約半額 | いちばん高い |
| 得意なこと | 簡単で答えがはっきりした作業 | 調べもの・解説・校正 | 判断が多い作業・長い作業 |

Tech Insiderによると、OpusとSonnetの値段の差は約2倍、SonnetとHaikuの差は約20倍です。また、Anthropicが公開したベンチマークではすべてSonnetがHaikuを上回っていて、Terminal-Bench 4.0ではSonnetが70.6%、Haikuが39.2%でした（LaoZhang AIの記事より）。

## effortって何？

effortは、Claudeがどれだけ時間をかけて考えるかを決める設定です。

| レベル | 日本語 | イメージ |
|---|---|---|
| low | 低 | さっと答える |
| medium | 中 | ふつうに考える |
| high | 高 | じっくり考える |
| xhigh | 超高 | かなり深く考える |
| max | 最大 | 限界まで考える |

上げるほど考える量が増えるので、答えを待つ時間とコストも増えます。

## effortを上げると、どれくらい変わる？

orcarouterの検証で、Sonnet 5.5のeffortごとの結果はこうでした。

| effort | スコア | 1タスクのコスト | 最初の出力まで |
|---|---|---|---|
| 低 | 35.84 | $0.41 | 1.04秒 |
| 中 | 40.74 | $0.59 | 1.34秒 |
| 高 | 46.74 | $1.08 | 16.6秒 |
| 超高 | 51.85 | $2.74 | 39.7秒 |
| 最大 | 55.98 | $7.60 | 378.8秒 |

この表からわかることは3つです。

- 低から高までは、スコアがしっかり伸びる。
- 高から超高は、スコアが約5点しか上がらないのに、コストは約2.5倍になる。
- **高より上は、だんだん割に合わなくなる。**

Anthropicのガイドでも、Sonnet 5.5はまずhighから始めて、xhighやmaxは効果を確かめてから使うことが勧められています。

## Sonnet超高とOpus中なら、どっち？

**迷ったらOpus中がおすすめです。**

Sonnetをxhighやmaxにしたくなる場面では、Opus 5.5をmediumかhighにしたほうが、同程度かそれ以下のコストで高いスコアが出ることが多い、と言われています（apidogの記事より）。Sonnetは1トークンの値段が安くても、超高にすると考える量が一気に増えるので、合計では高くついてしまうからです。

ただし例外もあります。Terminal-Bench 4.0ではSonnetが70.6%、Opus（xhigh）が66.4%で、Sonnetが上回りました。作業の種類によっては逆転することもあります。

## おすすめの使い分けルール

```
やりたいことは？
 ├─ ふだんの質問・簡単な作業
 │     → Sonnet 低〜中
 │       （利用上限が厳しいときは Haiku）
 ├─ 調べもの・文章校正・問題の解説
 │  （ちょっと複雑なものも含む）
 │     → Sonnet 中〜超高
 │       （複雑さに合わせて上げる）
 └─ それ以外（設計・計画・大事な文章など）
       → Opus 中
```

| 作業 | おすすめ |
|---|---|
| ふだんの質問、簡単な作業 | Sonnet 低〜中 |
| 利用上限が厳しいとき | Haiku |
| 調べもの、文章校正、問題の解説 | Sonnet 中〜超高 |
| 設計、計画、文章の構成づくり | Opus 中 |
| 提出用の大事な文章 | Opus 中（仕上げは高） |

### 迷ったときのコツ

- **Sonnetは、まず中から始めて、足りなければ上げる。** 高まで上げれば、たいていのことは足ります。
- **超高まで上げても納得できないときは、さらに上げずOpus中に切り替える。** そのほうが、コストも待ち時間も抑えやすいです。
- **Haikuは軽い用事だけ。** 難しい解説や、調べてまとめる作業は、考え方や情報の選び方が雑になりやすいので避けます。

## まとめ

```
Haiku           → 利用上限が厳しいときの軽い用事
Sonnet 低〜中   → ふだん使い
Sonnet 中〜超高 → 調べもの・校正・解説
Opus 中         → それ以外の「考える」作業
```

いちばん確実なのは、同じ質問を複数のモデルに投げて比べてみることです。特に文章の書き方は好みが出やすいので、一度試してみる価値があります。
